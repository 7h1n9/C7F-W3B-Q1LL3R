# 毕业设计任务书

## 一、主要任务

在 Python FastAPI 与 Muteki 多智能体黑板架构基础上，设计并实现一套面向本地 CTF 靶场与授权测试目标的多引擎 Web 安全自动推理系统，旨在解决传统自动化安全测试中状态分散、模型误判、工具协同困难与过程不可复现等核心问题，以满足现代网络安全训练与授权漏洞验证对自动化、可观测与证据可信的迫切需求。

本系统采用一体化设计，集成四大核心模块。共享黑板模块依托 SharedGraph 事实库实现事实、假设、意图、死路与证据引用的统一管理与持久化恢复，为多 Worker 并行协作提供状态唯一来源。多引擎 Worker 池模块支持 Codex CLI 与 OpenAI 兼容 API 等多类引擎并行接入，基于路线分配、死路共享与引擎探活自动重激活机制避免重复探索，充分发挥异构模型能力互补优势。容器化执行与证据驱动完成判定模块将 Worker 运行于 Docker 容器内部，通过反向连接控制面完成工具调用与黑板读写，由独立完成判定门依据已验证 Finding 与有效证据链作出完成决策，无证据不得判定任务完成。可视化工作区与审计模块依托 React 前端实时展示阶段切换、Worker 状态与事实更新，提供案情分析板、Token 用量统计、POC 导出与 Writeup 生成等功能，并通过全链路审计事件保证求解过程可追溯、可复现。

系统运行遵循 Prepare、Race、Coordinator、Finalize 四阶段流程，通过侦察、分类、规划、执行、复核与收尾的闭环，在无人值守情况下对授权目标完成自动求解，最终输出可复现的解题结论与完整证据链。最终，系统将通过全面的功能与性能测试，在本地靶场多类题型与多引擎并发场景下验证其可用性、稳定性与可靠性。本方案通过整合黑板协作、多引擎并行、容器化执行与证据驱动判定，为安全训练与授权测试提供了一个轻量级、可观测、可扩展的自动化推理基础方案。
