## 约定

- 新的一次性分析笔记放 `notes/YYYY-MM/`，命名 `YYYY-MM-DD-主题.md`。
- 根目录只增两类：**长期有效的说明文档**、**当前计划**。计划被新计划取代后，旧计划移入 `archive/`。
- 代码注释里引用文档请写**完整路径**（含 `notes/` 或 `archive/`），避免再次失效。
- 原始数据转储（`.jsonl`、`.tsv`、`.pkl`）不进 `docs/`，放 `.probe/`（已 gitignore）或 `data/backups/`。
